Privacy policy

Content Queue · Last updated October 26, 2026

Development-stage notice. The application has not launched. This notice distinguishes the public website from the planned private application. It will be reviewed and updated before the application processes live account data.

Who this notice covers

Content Queue is a private project for one crochet creator's own Pinterest account. It is not a service open to public registration. For privacy questions, contact the project operator at chipikagent@gmail.com.

This public website

The website consists of static informational pages intended for hosting on GitHub Pages. These pages contain no contact forms, analytics scripts, advertising, tracking pixels, embedded media, or application login. They do not expose the private application's images, messages, publishing queue, or credentials.

When the site is served through GitHub Pages, GitHub processes request information, such as IP addresses and technical connection data, under its own Privacy Statement. The project does not add its own visitor tracking. Sending an email to the contact address shares the information in that email with the operator and the email service used to handle it.

Planned application data and purposes

The following processing is planned, subject to implementation and Pinterest access approval:

  • Owner-supplied content: original images, titles, descriptions, and destination links, used to prepare and publish the Pins requested by the owner.
  • Publishing instructions: the selected board, approval decisions, and scheduled times, used to ensure that only specifically approved Pins are submitted.
  • Authorization information: OAuth credentials required to connect the owner's Pinterest account. The application will not request or store the owner's Pinterest password.
  • Operational information: delivery status and error information necessary to operate the queue and investigate failures. Retention of Pinterest-derived information will be limited to what Pinterest's applicable terms permit; the application is not intended to archive API responses or build a dataset of Pinterest content.

The intended storage location for the private application's data is the operator's Linux server, separate from this public website and its source repository. Implementation details and retention controls will be finalized before launch.

Services involved

Telegram will carry the owner's submitted content and approval messages. Pinterest will receive the content and instructions necessary to create approved Pins. YouTube and Patreon links are intended as destinations selected by the owner; this does not imply access to private data on those services. These services handle data according to their own policies.

AI-assisted descriptions and link suggestions are planned but disabled. No AI provider has been selected for this application. Before activating an AI feature, the operator will identify the provider, disclose what owner-supplied content would be sent and its handling, update this notice, and obtain the owner's authorization. Pinterest-derived data will not be used to train or improve AI models.

The planned application has no advertising or data-selling function.

Approval, access, and deletion

The owner will review each Pin's content, destination, board, and scheduled time before publication. Connecting the account will require Pinterest authorization. The owner can revoke that authorization through Pinterest's connected-app controls.

To request access to, correction of, or deletion of data held by the project, or to request that processing stop, email chipikagent@gmail.com. The operator may need to verify that the request comes from the account owner. No fixed retention period is claimed while the application is in development; retention and any backup-deletion limits will be documented before launch.

Deleting a local queue entry or disconnecting the application does not automatically remove a Pin already published on Pinterest or messages held by Telegram. Those copies must be managed through the corresponding service.

Changes

This notice will be updated as the implementation is finalized. Material changes to the planned processing, including AI-provider activation, will be brought to the owner's attention before that processing begins. The date above identifies the latest revision.
