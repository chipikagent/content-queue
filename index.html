Content Queue

A private tool being developed to help a private crochet creator prepare and schedule original content for one Pinterest account.

This website provides information about the project. It does not provide access to the application, a content queue, or a Pinterest account. There is no public registration.

Planned workflow

  1. The account owner supplies original crochet images and related YouTube or Patreon links in a private Telegram topic.
  2. The tool prepares a draft Pin with an image, title, description, destination link, board, and scheduled time.
  3. The owner reviews and explicitly approves each Pin before it enters the publishing schedule.
  4. Subject to Pinterest API access approval, the tool publishes one approved Pin per day to the owner's selected board.

Owner-controlled publishing

The planned application will run on a privately operated Linux server. Pinterest access will use OAuth authorization rather than collecting a Pinterest password. The application is intended only for the creator's own content and account.

AI-assisted draft descriptions and link suggestions are planned. These features are not enabled. A provider and its data handling will be disclosed, and the owner must authorize the feature before any content is sent for AI processing.
